# O que é um ADR
Um *Architecture Decision Record* é um documento curto que registra **uma** decisão técnica importante: o contexto, o que foi decidido, as alternativas consideradas e as consequências. Ele responde, meses depois, a pergunta *"por que fizemos assim?"*.

# Quando escrever
- A decisão muda a arquitetura, o custo, a segurança ou é difícil de reverter.
- Houve mais de uma alternativa razoável e o time precisou escolher.
- Alguém vai perguntar "por quê?" daqui a seis meses.

# Como criar
1. Crie uma página nova a partir do [template de ADR](/templates/adr).
2. Caminho: `engenharia/adrs/NNNN-titulo-curto` para decisões gerais, ou `projetos/<cliente>/<projeto>/adrs/NNNN-titulo-curto` para decisões de um projeto.
3. Adicione uma linha na tabela abaixo.
4. ADRs não são apagados: quando uma decisão muda, crie um novo ADR e marque o antigo como **Substituído**.
