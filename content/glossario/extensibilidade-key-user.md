**Também conhecido como:** `Key User Extensibility` · `In-App Extensibility` · `Extensibilidade In-App` · `Custom Fields and Logic` · `Custom Business Objects` · `Custom CDS Views` · `UI Adaptation`

> **Definição**
> Extensões low-code/no-code feitas pelo key user no Fiori (campos, lógica, UI, CDS e BOs customizados), estáveis a upgrades.
{.is-info}

Apps do Fiori Launchpad:
- **Adapt UI / UI Adaptation:** adicionar, mover, ocultar campos; renomear.
- **Custom Fields (and Logic):** Z-fields do banco à UI + BAdIs liberadas para lógica simples.
- **Custom Business Objects:** apps simples com tabela, lógica e UI próprias.
- **Custom CDS Views:** novas visões analíticas/APIs combinando fontes liberadas.

Analogia: *in-app* é "redecorar a sala". Empodera os *Fusion Teams* e libera os desenvolvedores pro-code para problemas complexos.
