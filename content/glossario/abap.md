**Também conhecido como:** `Advanced Business Application Programming` · `ABAP Clássico`

> **Definição**
> Linguagem de programação de alto nível da SAP, otimizada para aplicações de negócio, que roda no SAP NetWeaver ABAP Application Server.
{.is-info}

Todo código customizado do S/4HANA roda no **ABAP Application Server** sobre o banco HANA.

Evolução: ABAP procedural (programas, módulos de função) → [ABAP OO](/glossario/abap-orientado-a-objetos) → [CDS](/glossario/cds-view) + [RAP](/glossario/rap) → [ABAP Cloud](/glossario/abap-cloud).
