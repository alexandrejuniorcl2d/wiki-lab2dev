**Também conhecido como:** `View Browser` · `Customer Data Browser` · `SE16 do S/4HANA` · `Novo SE16`

> **Definição**
> Apps Fiori para funcionais: View Browser (catálogo para encontrar CDS por termo de negócio ou tabela) e Customer Data Browser (sucessor da SE16 para ver dados).
{.is-info}

**View Browser — como achar a view certa:**
1. Por contexto de negócio: "sales order", "purchase order", "billing document".
2. *Alternative Search*: por tabelas conhecidas do ECC (`VBAK*`, `MARA`) ou campos.
3. SAP Help Portal (views standard documentadas por produto).
> **Filtre sempre por status **Released** — só essas são estáveis para customizações.**
{.is-success}

**Customer Data Browser — o novo SE16:** abrir app → informar a view (ex.: `I_SALESORDER`) → filtros (empresa, org. de vendas, data) → executar; permite filtros, layout e exportação para planilha.

**Novas habilidades do funcional estratégico:** encontrar dados com autonomia, consultar/validar, "ler" a lógica (SQL básico e associações), entender code pushdown e ajudar a desenhar Embedded Analytics.
