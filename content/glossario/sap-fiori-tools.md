**Também conhecido como:** `Fiori Tools` · `Application Generator` · `Service Modeler` · `Page Map` · `Page Editor` · `Guided Development` · `SAP Business Application Studio` · `BAS` · `VS Code Fiori`

> **Definição**
> Extensões para VS Code e SAP Business Application Studio que aceleram apps Fiori: gerador de apps, modelador de serviço, Page Map visual e desenvolvimento guiado.
{.is-info}

- **Application Generator** (*Ctrl+Shift+P → Fiori: Open Application Generator*): template (ex.: List Report Object Page) → data source (serviço OData, ex.: Northwind V2) → entidade principal → `npm start` para rodar localmente.
- **Service Modeler:** visualiza entidades e propriedades do serviço.
- **Page Map:** árvore visual do app para adicionar/remover/reordenar colunas e filtros, ajustar labels e visibilidade — altera os arquivos de configuração com segurança.
- **Guided Development:** catálogo de extensões comuns (custom column, section, action, smart field) que insere o boilerplate nos lugares corretos.
- **SAP Business Application Studio (BAS):** IDE na BTP com dev spaces para Fiori, CAP e extensões; i18n editor; Adaptation Projects.
