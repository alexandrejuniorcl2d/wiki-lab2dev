## 📖 Termos

### Fundamentos
- [SAP Build](/glossario/sap-build) *(SAP Build Portfolio, SAP Build Lobby, Lobby)* — Oferta unificada de desenvolvimento na BTP que junta low-code (Build Apps, Process Automation, Work Zone) e pro-code (Build Code com Joule) para negócio e TI construírem juntos extensões limpas do S/4HANA.

### Low-Code
- [SAP Build Apps](/glossario/sap-build-apps) *(Build Apps, AppGyver, UI Composer)* — Ferramenta low/no-code do SAP Build para apps web e mobile nativos: UI por drag-and-drop, lógica visual em fluxos, fórmulas estilo Excel, integração via BTP Destinations/REST e backend no-code (Visual Cloud Functions).
- [SAP Build Process Automation](/glossario/sap-build-process-automation) *(SBPA, Process Automation, SAP Workflow Management)* — Solução low-code do SAP Build que combina workflows (aprovações, formulários, regras de decisão) e RPA (bots) para automatizar processos e tarefas repetitivas entre pessoas e sistemas.
- [SAP Build Work Zone](/glossario/sap-build-work-zone) *(Work Zone, SAP Build Work Zone Standard Edition, SAP Build Work Zone Advanced Edition)* — Portal da BTP (sucessor do SAP Launchpad Service) que cria sites de negócio e launchpads centrais com acesso único às apps Fiori, Build Apps e extensões, governado por catálogos, grupos e roles.

### Mobile
- [MDK](/glossario/mdk) *(Mobile Development Kit, SAP Mobile Development Kit, OData Offline)* — Framework baseado em metadados JSON para apps móveis nativos iOS/Android offline-first, com sincronização OData, acesso a hardware e integração com SAP Mobile Services.
- [SAP Mobile Services](/glossario/sap-mobile-services) *(SMS, Mobile Services, MobileEnabled)* — Serviço da BTP que envolve apps móveis nativos com autenticação (Cloud Identity, passcode), conectividade segura a destinations e features como push notification e upload de logs.

### Pro-Code
- [SAP Build Code](/glossario/sap-build-code) *(Build Code, Storyboard, Service Center)* — Ambiente pro-code do SAP Build, evolução do Business Application Studio com IA generativa (Joule): dev spaces prontos para CAP, Fiori/UI5 e MDK, com Storyboard, Service Center, Git, testes e integração a CI/CD.
