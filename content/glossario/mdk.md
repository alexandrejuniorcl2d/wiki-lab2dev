**Também conhecido como:** `Mobile Development Kit` · `SAP Mobile Development Kit` · `OData Offline`

> **Definição**
> Framework baseado em metadados JSON para apps móveis nativos iOS/Android offline-first, com sincronização OData, acesso a hardware e integração com SAP Mobile Services.
{.is-info}

- **Arquitetura:** você define páginas, ações e regras em JSON; o cliente MDK no dispositivo renderiza componentes 100% nativos — sem escrever Swift/Kotlin.
- **Capacidades:** offline robusto (**OData offline** sync para longos períodos), hardware (câmera, GPS, código de barras, biometria), segurança enterprise (Mobile Services), controles nativos customizados se necessário.

| Critério | MDK | SAP Build Apps |
|---|---|---|
| Público | Pro-code, TI | Citizen developers |
| Paradigma | Metadados + código | Visual drag-and-drop |
| Offline | Offline-first granular | Básico (on-device storage) |
| Extensibilidade | Alta (controles nativos) | Limitada (componentes e fórmulas) |
| Cenário | Técnico de manutenção com ordens e manuais offline | Registro de visitantes, formulário de feedback |
