**Também conhecido como:** `Cloud ALM` · `Solution Manager` · `SolMan` · `ALM` · `Application Lifecycle Management`

> **Definição**
> Soluções de gerenciamento do ciclo de vida de aplicações: Cloud ALM (nuvem, leve, guiado pelo Activate) e Solution Manager (on-premise).
{.is-info}

| SAP Cloud ALM | SAP Solution Manager |
|---|---|
| Nuvem, pré-configurado, guiado pelo Activate | On-premise/híbrido complexo |
| Projetos e operações de S/4HANA Cloud | ChaRM (gestão de mudanças), documentação, monitoramento detalhado |

Também usado para **observabilidade** de aplicações BTP, ao lado do SAP Application Logging e do Dynatrace. Solution Manager tem manutenção até 2027 (estendida a 2030) — Cloud ALM é o sucessor.
