**Também conhecido como:** `SAP GUI` · `Dynpro` · `Web Dynpro` · `Web Dynpro ABAP` · `BSP` · `Business Server Pages` · `SAP GUI for HTML`

> **Definição**
> Interfaces clássicas do SAP (SAP GUI com Dynpro, Web Dynpro, BSP) — stateful e renderizadas no servidor; legado a ser substituído por Fiori/SAPUI5 em novos desenvolvimentos.
{.is-info}

| Tecnologia | Status (DSAG) | Ação |
|---|---|---|
| Dynpro clássico | Não suportado no cloud | Manutenção restrita (power users on-premise) |
| BSP / Web Dynpro Java | Apenas suporte | Erradicar |
| Web Dynpro ABAP | Apenas suporte | Preterir em favor do SAPUI5 |
| SAP Screen Personas | Ferramenta cirúrgica | Só para simplificar telas legadas existentes |
