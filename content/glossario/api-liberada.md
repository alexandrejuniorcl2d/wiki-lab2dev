**Também conhecido como:** `Released API` · `Released Object` · `Release Contract` · `Contrato de Liberação` · `C0` · `C1` · `C2` · `API Hub`

> **Definição**
> Objeto SAP (CDS, classe, BAdI, API) com contrato de estabilidade: C0 extensão, C1 uso interno no sistema (ABAP Cloud), C2 uso remoto.
{.is-info}

| Contrato | Garantia |
|---|---|
| **C0 — Extensão** | Âncoras estáveis para adicionar campos/extender (ex.: views `E_*`) |
| **C1 — Uso interno** | Uso dentro do sistema em desenvolvimento ABAP Cloud (ex.: views para cubos/queries locais) |
| **C2 — API remota** | Exposição via APIs para integrações externas (SAP e não-SAP) |

Consulta: ADT (propriedade *API State*), app *View Browser* e SAP Business Accelerator Hub (api.sap.com).
