**Também conhecido como:** `PA` · `Personnel Administration` · `Infotipos` · `Infotype` · `IT0000` · `IT0001` · `IT0002` · `IT0008` · `Medidas de Pessoal`

> **Definição**
> Dados mestres do colaborador organizados em infotipos com histórico, manipulados por medidas (admissão, promoção, desligamento).
{.is-info}

| Infotipo | Conteúdo |
|---|---|
| IT0000 | Medidas (status: ativo/inativo) |
| IT0001 | Atribuição organizacional (posição, unidade, centro de custo) |
| IT0002 | Dados pessoais |
| IT0006 | Endereços |
| IT0008 | Salário base |
| IT0009 | Dados bancários |

**Medidas (Actions):** sequência pré-configurada de infotipos para admissão, promoção/transferência, alteração salarial e desligamento.
