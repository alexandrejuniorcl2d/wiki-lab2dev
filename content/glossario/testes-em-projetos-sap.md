**Também conhecido como:** `Teste Unitário` · `SIT` · `System Integration Testing` · `Teste de Integração` · `Testes de Regressão` · `SAP Test Suite`

> **Definição**
> Pirâmide de testes: unitário (consultor/dev), integração de sistemas (SIT, ponta a ponta) e aceitação do usuário (UAT).
{.is-info}

Ferramentas: **SAP Test Suite** (Solution Manager / Cloud ALM) para planejar e documentar; automação para **testes de regressão** a cada release.
