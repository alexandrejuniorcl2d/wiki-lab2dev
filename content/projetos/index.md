# Estrutura
Cada cliente tem uma pasta e cada projeto uma página, criada a partir do [template de projeto](/templates/projeto):

```text
projetos/<cliente>/                 visão geral do cliente
projetos/<cliente>/<projeto>        documentação do projeto
projetos/<cliente>/<projeto>/adrs   decisões de arquitetura do projeto
```

Use nomes curtos, em minúsculas e sem acentos. Exemplo: `projetos/cliente-x/migracao-pi-po`.

# Acesso restrito
> **Informação de cliente é confidencial.**
> Páginas em `projetos/<cliente>` devem ser visíveis apenas para a equipe daquele cliente. O acesso é configurado por grupo em *Admin > Grupos > Regras de página* (caminho começa com `projetos/<cliente>`). Peça ao time de Arquitetura ao iniciar um projeto.
{.is-danger}

**Nunca** registre senhas, tokens, certificados ou dados pessoais. Aponte para o cofre de senhas e para os repositórios oficiais.
